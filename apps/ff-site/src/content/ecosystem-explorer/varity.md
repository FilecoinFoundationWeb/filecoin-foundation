Varity is the Orchestration Cloud: a PaaS, a cloud, an AI gateway, and a vibe-coding builder in one, on one bill.

Static sites deployed with Varity (plain HTML, React and Vite SPAs, static Next.js exports, Vue, Astro) are published to IPFS and served through Varity's gateway, so developers get content-addressed hosting without running a node, pinning files, or touching any IPFS tooling. One command from the Varity CLI, or from an AI editor through the Varity MCP server, builds the site, publishes it to IPFS, and returns a live URL.
